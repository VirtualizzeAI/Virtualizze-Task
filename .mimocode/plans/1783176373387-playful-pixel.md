# Fix Kanban page scrolling - keep header fixed, only columns scroll

## Problem
The entire Kanban page scrolls together (header, buttons, columns) because the `<main>` wrapper in Layout doesn't constrain its height. `.kb-page` sets `height: calc(100vh - 52px - 3rem)` but the parent `<main>` grows unbounded, so the constraint is ignored.

## Layout hierarchy
```
.main-area (flex column, flex:1)
  .topbar (52px, sticky)
  <main> (no height constraint - THIS IS THE PROBLEM)
    .kb-page (height: calc(100vh - 52px - 3rem) - ignored by parent)
      .kb-topbar (flex-shrink: 0)
      .kb-board (flex: 1, overflow-x: auto)
        .kb-column (flex column)
          .kb-col-header
          .kb-col-body (overflow-y: auto)
```

## Fix (2 changes)

### 1. `src/components/Layout/style.css`
Add `flex: 1; min-height: 0; overflow: hidden;` to `<main>` so it constrains its children to the remaining viewport height.

The `<main>` element is a direct child of `.main-area` (flex column). Without `min-height: 0` and `overflow: hidden`, it grows to fit its content instead of being constrained by the flex container.

### 2. `src/pages/Kanban/style.css`
Remove the hardcoded `height: calc(100vh - 52px - 3rem)` from `.kb-page` since `<main>` now handles the constraint. Use `flex: 1; min-height: 0;` instead so it fills whatever space `<main>` provides.

## Files to modify
- `src/components/Layout/style.css` - add flex constraints to `<main>`
- `src/pages/Kanban/style.css` - replace hardcoded height with flex-based sizing

## Verification
- Open the Kanban page
- The topbar and `.kb-topbar` (project selector, buttons) should stay fixed
- Only the `.kb-board` should scroll horizontally (columns)
- Within each column, `.kb-col-body` should scroll vertically if cards overflow
