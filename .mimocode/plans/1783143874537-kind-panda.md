# Plano: Funcionalidade de Apagar Tarefas e Projetos

## Contexto

O app é um gerenciador de tarefas (React + TypeScript + Vite) com backend Supabase (localStorage como fallback). Atualmente suporta criar e editar, mas **não possui funcionalidade de exclusão**. O banco já tem `ON DELETE CASCADE` configurado e RLS policies de delete.

## Arquivos a modificar

| Arquivo | Mudança |
|---|---|
| `src/context/AppDataContext.tsx` | Adicionar `deleteTask`, `deleteTaskTodo`, `deleteProject` |
| `src/pages/Tasks/index.tsx` | Botão de excluir no modal de detalhe da tarefa |
| `src/pages/Projects/index.tsx` | Botão de excluir no modal de visualização/edição do projeto |
| `src/pages/Kanban/index.tsx` | Botão de excluir no modal de detalhe da tarefa no Kanban |

## 1. Context: Funções de exclusão (`AppDataContext.tsx`)

### `deleteTask(taskId: string)`
- **Supabase**: `DELETE FROM tasks WHERE id = taskId` (cascata para `task_todos`)
- **localStorage**: Remove task do array `tasks` e todos relacionados de `taskTodos`

### `deleteTaskTodo(todoId: string)`
- **Supabase**: `DELETE FROM task_todos WHERE id = todoId`
- **localStorage**: Remove todo do array `taskTodos`

### `deleteProject(projectId: string)`
- **Supabase**: `DELETE FROM projects WHERE id = projectId` (cascata para `project_stages`, `tasks`, `task_todos`, `client_projects`)
- **localStorage**: Remove projeto, stages, tasks e taskTodos relacionados

Todas as funções seguem o padrão existente: atualizar state local primeiro, depois persistir.

## 2. UI: Páginas
